# PR Description preferences

- Match this repository's existing PR/commit style for headings and tone; the six-part shape stays,
  the exact wording does not have to.
- Prefer real, runnable reviewer-checklist items (a command, a URL) over prose instructions.
- Omit a section entirely rather than filling it with "N/A" — an absent section reads as "not
  applicable here"; a filled one implies there was something to say.
