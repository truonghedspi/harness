# Harness global skill: human-interview

When progress depends on business intent, risk appetite, ownership, environment facts, acceptance
criteria, permissions, priorities, or another human-owned assumption, read and apply
`{{SKILL_PATH}}` before asking. Do not invoke it for facts available from code, tools,
documentation, or a safe probe.

This steering file is always available so the trigger cannot be missed; it does not make every
conversation an interview. The installed `SKILL.md` is authoritative for the workflow and
boundaries.
