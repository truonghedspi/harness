# Human Presenter preferences

- Match the user's language; preserve English technical terms when translation would reduce precision.
- Default to concise, collaborative prose. Use headings only when they improve scanning.
- Prefer local clickable file links and direct primary-source web links.
- Prefer the smallest useful visual; dark standalone SVGs are welcome only when the relation merits one.
- Never add a generic “Sources” section to a short answer with one or two unobtrusive inline links.
