# Comparison, recommendation, proposal, and research summary

For comparison, establish stable criteria first and use a table only when each option can be judged
on the same axes. Do not pad the option set or hide a criterion that changes the winner.

For recommendation, lead with the choice, then the decisive reason, main downside, strongest
credible counter-case, uncertainties that could change it, and next action. Analysis informs human
values; it does not manufacture risk appetite or authority.

For a consequential proposal, also state reversibility, delay cost, what each option forecloses,
and where the decision will be recorded. Developing the option set belongs to a decision-proposal
skill; this skill presents established options faithfully.

For research, lead with findings and applicability. Separate source conclusions from adaptation or
inference. Group citations by claim cluster and prefer primary sources. End with limits or open
questions only when they affect use of the findings.
