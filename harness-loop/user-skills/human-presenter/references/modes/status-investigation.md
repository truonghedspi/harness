# Status and investigation

Status order:

1. Is it moving? Lead with the delta, not the absolute inventory.
2. Is it going somewhere right? State the current/next node or outcome.
3. Does the reader need to act? Name one blocker/decision, or explicitly say no.
4. Show cost only when it affects a decision: time, attempts, failures, or resource use.

Investigation order:

1. Current conclusion and its scope.
2. Confirmed observations, including commands/environment when material.
3. Inference chain, naturally separated from observations.
4. Competing explanation or missing evidence that could overturn it.
5. Recommended next discriminating check or fix, depending on authorization.

Use a timeline for meaningful state change; a sequence diagram for ordering/race/retry; a table for
competing hypotheses with shared evidence. Skip visuals for a single cause.
