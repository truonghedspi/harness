# Answer and explanation

For a direct answer: answer in the first sentence, add only the reasoning needed to trust or use it,
then stop.

For an explanation: begin with the mental model, show the mechanism in causal order, add one example
only when it resolves ambiguity, and end with the implication. Use a flow or illustrative diagram
only when the reader would otherwise reconstruct three or more linked relations.

Do not turn a simple answer into a tutorial. Do not start with background before revealing why it
matters.
