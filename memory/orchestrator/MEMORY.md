# orchestrator — memory index

One line per entry: `- [title](file.md) — hook`. Keep each line short; detail lives in the entry.

What is worth writing here: a question the human answered and where the answer landed, a routing
decision that surprised you and why, a stop condition you hit and what cleared it. Not the state —
`tools/loop-status.mjs` reads that live, and a copy here would go stale.

Write entries and hooks **in English**, whatever language the rest of the project uses: memory is
addressed to whichever agent reads it next, not to this project's readers. Entries already written
in another language stay as they are — this governs what gets written from now on.
