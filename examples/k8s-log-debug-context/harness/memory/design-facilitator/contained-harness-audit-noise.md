The fresh scaffold has no product directories yet, while its harness includes test-design and
business-journey skill files. The audit therefore reports inherited identity, retry, ordering,
failure-reporting, and observability terms as project concerns. Treat those as audit-scope noise
until product artifacts use the terms; record only policies introduced by the actual design.
