# Context documents

Domain and business knowledge elicited from people, distilled by the agent that found the gap using
the user-scope `human-interview` skill
into documents the later steps can act on. Each is **≤300 lines** and indexed in `harness/docs/INDEX.md`
with a "read it when" line (`harness/docs/reference/knowledge-layout.md`).

Never a raw interview transcript — a transcript makes the next agent re-derive the conclusion.
Write what a future agent needs in order to act.
